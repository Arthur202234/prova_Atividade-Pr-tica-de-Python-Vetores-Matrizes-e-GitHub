Estudo de caso:

1. Controle de chamados do laboratório de informática: 

Uma escola técnica possui um laboratório de informática utilizado diariamente por 
alunos e professores. Durante as aulas, podem ocorrer problemas relacionados a 
computadores, programas, acesso à internet e equipamentos.
 
O responsável pelo suporte técnico precisa acompanhar a quantidade de 
chamados registrados de segunda a sexta-feira, identificando os dias com maior 
demanda.
 
Atualmente, essas informações são registradas manualmente. Para facilitar o 
acompanhamento, a escola solicitou o desenvolvimento de um programa em 
Python. 

2.Controle de vendas de uma Feira Tecnológica:

Durante uma Feira Tecnológica, os estudantes organizaram três estandes para 
comercializar produtos personalizados: 
• Camisetas 
• Canecas 
• Bonés 
A feira acontecerá durante dois dias, com atividades nos períodos da manhã e da 
tarde. 
Para organizar o resultado das vendas, os estudantes precisam registrar a 
quantidade de produtos vendidos em cada um dos quatro períodos. 
A organização da feira solicitou um sistema que permita analisar os resultados 
utilizando uma matriz de três linhas e quatro colunas (3 × 4).


Como executar o programa: 

Para executar o programa, será necessário utilizar um editor de códigos como o Visual Studio Code ou Pycharm.

Passo a passo: 

1. Instale o Visual Studio Code e a extensão do python. 
2. Instale o arquivo do GitHub e abra-o no vs code. 
3. Após as etapas anteriores, clique em executar no vs code ou aperte a tecla F5.
4. O vs code abrirá um terminal, onde o código será executado.
